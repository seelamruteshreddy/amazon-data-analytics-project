#Amazon Sales Data Analytics Project

Overview

This project analyzes Amazon product sales data using Python. The project focuses on customer purchasing behavior, product ratings, discounts, reviews, and sales trends.

The analysis helps identify top-performing products and business insights using data analytics and visualization techniques.

---

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

Dataset Features

- Product Title
- Product Rating
- Total Reviews
- Purchased Last Month
- Discounted Price
- Original Price
- Best Seller Status

---

Project Objectives

- Analyze Amazon product sales trends
- Study customer purchasing behavior
- Compare discounted and original prices
- Identify top-rated products
- Visualize business insights using charts

---

Data Analysis Steps

1. Data Collection
2. Data Cleaning
3. Handling Missing Values
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Business Insights Generation

---

Visualizations Included

- Bar Charts
- Histograms
- Heatmaps
- Scatter Plots

---

Business Insights

- Highly rated products received more purchases
- Discounted products showed increased customer interest
- Products with more reviews had higher sales performance
